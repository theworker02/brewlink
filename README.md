# brewlink

Brew encode/decode helpers for link payloads in pipelines.

**Site:** https://theworker02.github.io/brewlink/

## Install / run

```bash
git clone https://github.com/theworker02/brewlink.git
cd brewlink
node src/cli.js
node --test
```
